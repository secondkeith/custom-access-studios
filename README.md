# Custom Access Studios

Static concept website for Emily's accessibility guidance and coordination studio. Status: **public design preview, not accepting inquiries**. Business scope, service area, credentials and public contact details remain unconfirmed.

## Preview
Run `python3 -m http.server 8765 --bind 127.0.0.1` in this directory. No build or runtime dependencies.

## Files
- `index.html`: editorial home page; service paths, illustrative possibilities, process, local-only note download.
- `styles.css`, `script.js`: responsive styles and progressive enhancement.
- `accessibility.html`: accessibility, privacy and preview limitations.
- `image-briefs.html`: Gemini prompts and image delivery guidance.
- `BRIEF.md`: agreed positioning and constraints.

## Publication
GitHub Pages, main branch root. No custom domain configured. `noindex,nofollow` remains until launch approval; this does not make the site private.

## Before launch
Confirm business scope and Emily's preferred bio; add verified service area/contact; choose a real inquiry delivery method and privacy handling; replace atmosphere reference with approved imagery; obtain client consent for any case studies; verify keyboard/screen-reader and real-device usability; remove preview labels/noindex only after approval. No engineering, clinical, licensing or accessibility compliance claims are made.
